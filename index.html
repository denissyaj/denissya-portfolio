📸 Technical Support System - Screenshots

Below are the actual screenshots of the Technical Support System I developed:

1. Create Request

  • Structured technical support request form
  • Select job type (Repair/Maintenance)
  • Select problematic asset/machine
  • Problem description and photo upload
  • Assign responsible section (Maintenance/Utility/Workshop/Civil)
  • Auto-generate request number

2. Approval Requester Manager (Level 1)

  • Requester's supervisor receives notification
  • Check request completeness and accuracy
  • Approve or Reject with required comments
  • Status changes to "Waiting for TK Manager approval"

3. Approval TK Manager (Level 2)

  • Technical manager evaluates the request
  • Check resource, technician, and equipment availability
  • Final approval or rejection with required comments
  • After approval, request goes to technician assignment

4. Close Ticket

  • Technician inputs work results and completion steps
  • Record spare part usage and part code
  • Fill completion date and time
  • Upload documentation photos of work results
  • Requester verifies the work results
  • System auto-closes ticket after verification

5. History

  • Store complete technical support request history
  • Searchable by request number, asset, or period
  • Display complete details (submission, approval, execution, closure)
  • Show approval log with timestamp
  • Accessible anytime for audit purposes

6. Quality Report

  • Request count report by status and period
  • Work completion duration report (Completion Time)
  • Spare part usage report (Part Code)
  • Technician performance report (Executor)
  • Filter by date, department, maintenance status
  • Export data to PDF/Excel format
  • MTTR (Mean Time To Repair) calculation
